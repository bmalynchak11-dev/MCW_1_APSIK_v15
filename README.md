# Стартовий проєкт

1. Відкрийте проєкт у GitHub Codespaces (Code → Codespaces → Create codespace) або локально на Linux/WSL2: `pip install -r requirements.txt`.
2. Знайдіть у теці `tasks/` теку свого номера (`task_NN/`) і реалізуйте файли за карткою завдання. Файл `task_NN.py` службовий, його не змінюйте.
3. Запускайте відкриті тести: `pytest` (або `pytest tests/test_task_NN.py`).
4. Змінюйте лише файли у своїй теці, файл `ANSWERS.md` і власні файли `answers/task_NN.md`.
5. Теоретичні завдання 11–15 не мають тестів: напишіть відповідь у файлі `answers/task_NN.md` під рядком «Відповідь:».
